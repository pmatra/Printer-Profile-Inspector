# Adversarial review resolution

Reviewed against the supplied v0.4.0 assessment; local implementation v0.6.0,
2026-11-19. Earlier fixes shipped in v0.5.2 are retained. This document records
local evidence, not a claim that a new GitHub Actions run/release has occurred.

| Review item | Resolution and evidence |
| --- | --- |
| Missing application license | MIT LICENSE, third-party notice index and full collected texts are included in source and beside the Windows executable. Qhull/HiGHS and other embedded SciPy notices were added during this review. |
| GPU mesh cache keyed only by object id | Entries retain their source object and now additionally verify `cached_source is result` before reuse. GPU regression deliberately injects a stale entry and verifies replacement. |
| Interrupted settings writes | Same-directory temporary file, flush/fsync, atomic replacement, prior known-good backup and explicit corrupt-file recovery/quarantine. Failure/recovery regressions pass. |
| Concurrent instances overwrite categories | A per-user Windows named mutex prevents a second normal app instance, including another release folder. Cross-process regression passes. |
| Profile List parses full profiles on UI thread | Directory scan reads only 132-byte headers, validates declared/table sizes against file size, and runs off-thread. Opening the Inspector still fully validates all tag bounds. GUI heartbeat/stalled-scan tests pass. |
| Sampling/parsing/hull freeze and no cancellation | Full parsing and sampling run on a worker; chunked transform progress goes through a queue consumed by Tk. Cancel invalidates results and cooperatively stops scan/sampling/export. A native read/transform-build/hull call cannot be killed mid-call; it finishes without publishing cancelled output. Stalled parsing, GUI heartbeat and cancellation tests pass. |
| Permanent deletion in system directory | Recycle Bin only, filename-specific Yes/No defaulting No, fixed-drive restriction, explicit system-color-directory warning and no permanent-delete fallback. OS calls remain mocked in regressions. |
| Convex hull can misrepresent actual gamut | Persistent warning inside the CPU/GPU viewport, labelled metrics, README limitations. A concave/alpha-shape renderer is not implemented; it was a future suggestion rather than a correctness fix. |
| No quantitative comparison | Background calculation of primary/comparison hull volume, convex-polyhedron intersection volume and comparison/primary ratio. Synthetic identical, contained, partial, touching and disjoint polyhedra pass known-value regressions. These are hull estimates, not actual printer-gamut volume/overlap measurements. Gray/degenerate sets have no 3D volume. |
| Pillow's internal signed-byte Lab layout | Conversion now uses the public pixel API and offset-binary decoding. Pillow pinned to 13.0.0. A fixed generated ICC asset checks black/white and saturated-primary D50 Lab anchors, including negative chroma. Vendor printer profiles are not redistributed. |
| Category filename collisions/orphaned mappings | Exact filename membership avoids case folding collisions. Missing memberships are retained and reported in a persistent warning/category status. Recover categories copies saved assignments from an old folder location after rename/move and preserves the original location. Individual file renames still require explicit reassignment; they are reported rather than silently discarded. |
| No CI execution trail | Added `.github/workflows/checks.yml`: Windows runner, locked dependencies, Ruff correctness rules, four GUI/functional regression scripts, push/PR/manual triggers and minimal read permissions. The same checks passed locally. **Remote execution remains unverified until the workflow is pushed and a GitHub Actions run succeeds.** Hardware GPU checks remain separate real-device release checks. |
| No visible version | Shared `version.py`, About menu, source/packaged `--version`, Windows FileVersion/ProductVersion generated by the build. Packaged stdout capture and Windows resource properties verified as 0.6.0. |
| Sort direction/invalid timestamps | Heading arrows and persisted direction; invalid/unspecified timestamps are always last. Refresh/move/fold/restart plus ascending/descending invalid-date regressions pass. |
| Raw tags only | Descriptions, XYZ/white points, matrices, tone curves and common LUT structures decoded; raw fallback retained. Existing decoder and malformed-payload regressions pass. |
| CSV cannot reproduce samples/compare | Atomic, cancellable background CSV exports both datasets with device values, grid coordinates, density, intent, device space, role, sample index, profile SHA-256 and full Lab samples. A two-profile CSV round-trip regression passes. |
| Linear hover scan over 194k samples | Bounded to at most 5,000 representatives with a cached 2D KD-tree for nearest-point queries. GPU hitpoint construction is also capped; regression passes. |
| Fixed OpenGL near/far range | Depth extent derives from each dataset's 3D norm with margin, independent of rotation/zoom. Real-GPU test covers oversized geometry at zoom 8 and normal mode/resize transitions. |
| SmartScreen and unsigned executable | README explains unsigned-build warnings, possible false positives, checksum limits and future signing. **Code signing is not implemented; the build remains unsigned.** A disclaimer does not replace a signing certificate or publisher reputation. |

## Validation performed

- Ruff correctness rules: pass.
- `check_inspector.py`, `check_categories.py`, `check_upgrade.py`,
  `check_adversarial.py`: pass with temporary settings/files.
- `check_gpu.py` and packaged `--gpu-check`: pass on Intel Iris Xe hardware.
- Packaged `--version`: `ICC Profile Inspector 0.6.0`; executable file/product
  version: `0.6.0`.
- Native visual inspection: primary/comparison legend, estimated volumes and
  persistent approximation caveat visible in the GPU viewport.
- No real installed profile was installed, recycled or deleted during tests.

Remaining distribution work: push the updated source/workflow, verify the first
remote CI run, and publish the new release when desired. Signing and a concave
gamut renderer remain future features, not claims made by this build.
